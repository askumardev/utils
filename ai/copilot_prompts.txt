GitHub Copilot – Effective Prompt & Command Notes
1. Core Slash Commands (Most Used)
Command	Purpose	Example
+-----------+-------------------------------------+-----------------------------------------------------------+
| Command   | Purpose                             | Example                                                   |
+-----------+-------------------------------------+-----------------------------------------------------------+
| /explain  | Explains selected code              | /explain this ActiveRecord query and mention performance  |
| /fix      | Finds bugs and suggests fixes       | /fix this Ruby code that raises undefined method error    |
| /tests    | Generates unit tests                | /tests generate RSpec tests for this Rails controller     |
| /doc      | Generates documentation/comments    | /doc add documentation for this GraphQL mutation          |
| /optimize | Improves performance or readability | /optimize this N+1 ActiveRecord query                     |
| /generate | Creates new code from description   | /generate a Rails service object for Stripe payments      |
| /review   | Performs code review                | /review this Rails controller for improvements             |
| /refactor | Improves code structure             | /refactor this Rails controller using service objects     |
| /help     | Lists available commands            | /help                                                     |
| /new      | Starts a new chat session           | /new                                                      |
| /clear    | Clears the conversation             | /clear                                                    |
+-----------+-------------------------------------+-----------------------------------------------------------+

2. Context Commands (Very Powerful)
These allow Copilot to understand project context.

Workspace
@workspace explain the authentication flow in this project
@workspace find usages of OrderService

Specific File
Explain logic in #file:order_service.rb

Selected Code
Refactor #selection into a Rails service object

Terminal Errors
@terminal explain this error

7. Multi-Step Prompt (Best Practice)
Use structured prompts:

Analyze this Rails controller and:
1. Explain the code
2. Identify bugs
3. Suggest performance improvements
4. Generate RSpec tests
This gives much higher quality responses.
